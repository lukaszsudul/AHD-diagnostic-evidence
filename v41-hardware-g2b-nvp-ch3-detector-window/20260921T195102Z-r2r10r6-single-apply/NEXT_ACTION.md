# Następna czynność

Po osobnej zgodzie Ownera wykonać ograniczoną świeżą weryfikację synchronizacji CH3 istniejącym SCAN1 na zachowanym obrazie i boocie, bez ponownego PREPARE/APPLY, PN B, host RECOVER, DMA i capture.

Wynik R2R10R6 pozostaje pojedynczym sukcesem zgłoszonym przez eksperymentalny loader. Nie jest niezależnym potwierdzeniem synchronizacji i nie dowodzi przyczyny historycznego NACK.
