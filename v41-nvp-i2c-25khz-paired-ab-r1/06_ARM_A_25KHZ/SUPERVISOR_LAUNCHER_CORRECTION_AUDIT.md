The failed launch produced only the Windows error that the quoted settings
batch token was not recognized. It never started Vivado or sourced Tcl. Under
the controlling prompt, a program attempt is consumed only when
`program_hw_devices` begins; therefore this was not a programming attempt or a
programming retry.

The correction replaces `cmd.exe` `ArgumentList` serialization with the tested
raw `/d /s /c` argument form, rejects whitespace and command metacharacters in
every dynamic token, and supplies an explicit UTF-8 encoding to the two
evidence-append calls. An offline synthetic command using the same raw-token
form called the exact settings wrapper and emitted `I25_RAW_TOKEN_GATE_PASS`
with exit code zero. It launched no Vivado, Tcl, JTAG, or hardware operation.
