# AHD v41 — CONT1R3R4R5 W1/W2 offline result

## Decision

**Engineering gate: PASS for the authorized offline W1/W2 scope.** With the frozen scanner and master, one clean XSim 2025.2 SW 6299465 scan completed 82 entries and 105 transactions. Every one of the 10 successful group-bank-write resolved STOP→verify-read initial START intervals was **3,755 FPGA cycles, 60,080 ns = 60.080 µs**. The 10 verify-read STOP→first-entry initial START intervals and the successful terminal restore-write→verify interval were also 60.080 µs. Three group selects were same-bank reselections. Source derivation agrees with all 104 adjacent resolved-line transaction gaps; two deliberately corrupted boundary interpretations were rejected. The observed model value is 139.920 µs below the reference HI_I2C helper's 200 µs post-write-call wait and 239.920 µs below its I2C_INTERNAL helper's 300 µs wait. These are scoped numerical differences between our resolved digital model and reference code waits, not a physical reference-bus measurement, device settle rule, or NACK root-cause proof.

**Combined recommendation: `PROCEED_TO_W3_MINIMAL_OBSERVABILITY_AND_DELAY_AB`.** The timing difference supports a narrow, separately authorized default-OFF 300 µs post-successful-bank-select experiment. Its interpretation needs first and terminal error records, per-attempt SCL wait/ACK-phase data and successful same-kind controls. The proposal does not equate our entire initialization with the reference: the frozen FPGA uses fixed stage-2 AHD1080p25/CH1/VDO1 settings; the pinned reference driver starts detected channels in `1080P_NOVIDEO`, and comparable 1080P2530 plus EQ behavior is a later conditional path. The reference's F2/F4/F5 detector reads follow one bank select and require a caller. The selected Bank 5 values/order and port behavior also differ. A bank-select-only pause cannot repair a bank-select write whose data byte already lacked an ACK, reproduce waits after every reference write, or account by itself for all 11 historical read events, including group 3 position 8.

The **51 Bank 5 functional-write** claim is `CONFIRMED` as 51 ordered active stage-2 table rows at 37 unique Bank 5/register keys, excluding bank selects. The **three delay entries** claim is `CORRECTED`: the 214-slot selected table has one active FE delay opcode (slot 4), one FE opcode inactive at stage 2 (slot 135), and a separate executor WAIT_INIT. At the actual 25 kHz/62.5 MHz parameters, their nominal programmed spans are 20.016 ms and 240.192 ms respectively; source comments giving 10/120 ms are stale for this configuration. These waits are not per-bank post-write pauses. The W2 report gives all counting rules, generated bank transitions, reference branch conditions and source locations.
