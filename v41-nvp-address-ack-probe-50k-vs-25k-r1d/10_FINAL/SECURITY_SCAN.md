# Evidence security scan

`SECURITY_SCAN_MATCHES=0`

The curated task evidence tree was scanned case-insensitively for password,
secret, token, private-key, DUT credential-file, and supplied DUT-IP patterns.
Generated Vivado project/cache content, DCPs, bitstreams, crash dumps, and ZIPs
were excluded from text scanning. No credential file was read or copied.
