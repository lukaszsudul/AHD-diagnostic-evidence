# Scope and authorization

Authorized work comprised the diagnostic-only result-storage correction,
simulation, one fresh nonincremental diagnostic build, and—only after every
offline gate passed—one diagnostic programming and 4x4 capture scan. The
offline CDC disposition gate did not pass, so all hardware authorization
remained conditional and unused. Flash, power-cycle, PRODUCT source changes,
SSOT changes, and arbitrary NVP writes were not performed.
