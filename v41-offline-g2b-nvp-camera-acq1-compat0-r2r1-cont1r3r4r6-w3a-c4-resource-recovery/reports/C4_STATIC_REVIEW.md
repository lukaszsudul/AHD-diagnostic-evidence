# C4 targeted static review

The only RTL changes are in `g2b_nvp_camera_scan1.sv` and `g2b_nvp_camera_w3_telemetry.sv`. The C3 32-bit W3a read register and one-bit pending stage were removed. On acceptance of a W3a read, the scanner now captures the combinational W3a word into its existing 32-bit response register and asserts `mmio_rsp_valid`. The response remains held by the unchanged valid/ready logic. The old W3a register sampled pre-edge fields; the new scanner response register samples the same pre-edge fields. The 0x13800..0x1383C aligned register window and all zero responses for other addresses in the W3a page are preserved. The 0x13800..0x147FF page equals two 2 KiB blocks with high address values 0x27 and 0x28.

The W3a record capture, primary/cleanup priority and retention logic are unchanged. `failure_meta` remains latched at `bank_fail`, before a following transaction can clear its raw first cause. The first bank failure of a scan becomes primary and a later failed restore/restore verify becomes cleanup. Legacy ACK and a clean later scan do not clear retained records. The OFF/ON pause latch and 18,750-cycle counter path are unchanged. No I2C arbitration, low-level master, retry, capture, ACQ, table, IP, XDC or SSOT files changed.

`safe_idle` is textually unchanged and still checks IDLE, scan admission, executor, I2C and bus conditions, transaction in flight, pending snapshot and response. A pending W3a read now appears as `mmio_rsp_valid` instead of `w3_read_pending`; the hardware refuses configuration writes until the response is no longer pending. The host's status-bit guard is only an early check; it still validates hardware acceptance via the rejected-write counter. Status bit 1 keeps the RTL predicate `state >= 1 && state <= 9`, now labelled `SCAN_IN_PROGRESS`. Zero does not prove SAFE_IDLE.

No RTL dynamic equivalence claim is made. `XSIM_NEW_RUNS=0`; changed RTL behavioral assurance is `LIMITED_STATIC_REVIEW_AND_IDENTIFIED_HISTORY`. The historical 3,755/22,505 cycle readings belong to earlier source. C4 timing and resources require the new implementation reports.
