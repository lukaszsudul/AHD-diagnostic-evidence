# One possible future diagnostic/demo image — design note only

No implementation, build, new ABI, pin assignment, external observer or hardware action is authorized here. A future versioned image, if separately approved, should combine first-error observability with the minimum fixed-action camera path rather than create a generic host I2C port.

1. Latch the **first failed operation before any retry, bank restore or verify**: raw master cause, timeout, FSM phase, command kind/sequence, bank/register, validity, reset/reconfiguration epoch and source channel. Keep a separate terminal-error record or an unambiguous event count/sequence link so a later hard failure does not replace the first recovered event. Host acknowledgement may clear only in an idle/safe state. Reset/reconfiguration invalidates the latch with an explicit epoch change rather than looking like “no error”. Classify read REGADDR and write DATA failures separately; do not trigger on a normal master terminal read NACK.
2. If a bounded Bank5-select retry is separately justified, make enable default OFF after reset and writable only idle, then freeze it per operation/session. Limit attempts, record original and each retry cause, and require bank readback. Do not retry arbitrary functional configuration writes. Timeout, unsafe bus, failed restore/readback or unknown reset/configuration state hard-stop; never retry forever. The current image is unchanged and no such retry is enabled now.
3. Optional external trigger only after an exact unused routed pin/test point, voltage domain and safe access are demonstrated. A latched level or an observer-appropriate long pulse is required; a 16 ns clock pulse is not promised detectable by a 1–2 MHz observer. External analyzer thresholds are not FPGA thresholds. Neither new ILA nor XDC change is implied.
4. Determine whether the active autoinit *actually* supplies a camera's required static mode. Its source selects a fixed 1080p25 profile, but desired mode is not evidence that the physically connected camera emits that format, and current ACQ two-register actions are not MODE1. A separately governed fixed-action extension, if needed, must have exact register authority and deterministic rollback. Use one evidenced camera format and one channel; verify NOVID, relevant lock/format evidence, safe DMA ownership and a complete genuine C2H frame to Linux, then decode/display. Do not run a continuous 82-entry scanner as the demonstrator. No signal at a possibly wrong initial mode is not proof that configured acquisition is impossible.
5. The documentary Bank0/0x80 canary is not currently a fresh post-error one-register observation. Add a fixed read only if reset-class defaults, read side effects, epoch, bank ownership and post-error safety are separately proven. A cached snapshot is not enough. Otherwise omit the canary rather than make a false reset claim.

Inherit existing routed planning constraints only: LUT 19,738 versus ceiling 20,384; WNS +0.047 ns; WHS +0.036 ns. They are not a new measurement or guarantee that another image fits. A future changed image needs a concrete resource/timing budget and complete sign-off. The completed 25-scan history is not a 10,000-scan reliability qualification. Any first-frame exception is a separate explicit owner decision, with bounded actions and rollback; this offline note grants none.
