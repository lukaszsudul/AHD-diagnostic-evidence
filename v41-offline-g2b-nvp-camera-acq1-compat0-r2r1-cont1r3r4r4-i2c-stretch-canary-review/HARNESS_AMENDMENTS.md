# Task-owned harness amendments

The first frozen-grid attempt stopped at case 1 before accepting a result. The independent Python checker compared matrix field `op_read` with a nonexistent simulator key `op_read`; the simulator records that value as `read`. This was a checker-key mismatch, not a design result. The case-1 simulator and pin logs were retained privately; no sweep case was accepted. Amendment A1 maps `op_read` to `read`, changing only the task-owned checker. The 214-case matrix, timing rules, compiled unchanged RTL, bench and simulation snapshot did not change. Updated checker SHA-256 `1B3319A556DD2170F01BD6A78D480A7799F6DDE2D6873F31603E4576A723882D`; the amended frozen-hash receipt was installed before restarting at case 1. The original matrix and contract hashes remain unchanged. This is correction 1 of maximum 3 after preregistration.

The second attempt stopped at case 1 because the independent pin decoder counted the additional SCL-high interval used to form STOP as a data clock. The raw pin record explicitly showed 28 SCL rises for a clean write, with the final rise followed by STOP and no falling edge. Amendment A2 recognizes only a high pulse with a following resolved falling edge in the same START-delimited segment as a data/ACK bit clock. This also excludes repeated-START setup highs. It changes only the task-owned checker; original simulator and pin logs are retained and the matrix, compiled design and bench remain unchanged. Updated checker SHA-256 `5D38A7650F6610618A40D2C83EAFA9646F584851184CB53457DFFC51D1F5C977`. This is correction 2 of maximum 3 after preregistration; the full matrix restarts at case 1.

The third attempt verified cases 1–210, then stopped at intentionally illegal early-release control case 211. Its pin recorder saw two SDA-rise/STOP-like edges: the premature release during SCL HIGH (the intended invalid stimulus) and the controller's later STOP. The slave `active` counter counted only the first. Amendment A3 preserves both pin events and requires `ack_high_violation=1` and pin STOP count greater than the slave-active count for this explicitly invalid control; normal cases retain strict equality. This changes only the checker. Original case-211 waveform/log are retained; the frozen stimulus, source RTL and bench remain unchanged. Updated checker SHA-256 `163FA83D5621EFD7EBE9DA19294B5B2045991932F299AB16EE2C768557919EBA`. This is correction 3 of maximum 3 after preregistration. The full matrix restarts at case 1; no further harness correction is authorized in this task.
