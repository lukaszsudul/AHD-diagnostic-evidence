# Reset-canary feasibility

Final current-image disposition: `READABLE_BUT_NOT_RESET_DISCRIMINATING`. Bank0/0x80 is a promising *documentary* candidate: the NVP6134C Rev1.0 table §6.1.5 p41 labels `EACH_REG_SET`, `Def.=0x00`, `25P=0x0F`; the frozen autoinit overlay in `rtl/nvp/nvp6134c_diagnostics_pkg.vhd` selects Bank0 and writes full byte `0x0F` at overlay slot 1. It is SCAN1 entry 3 and is marked a non-partial read-safe snapshot entry. This task did not measure a live post-init value. The document's `Def.` column does not separate power-on, external RESETB and software reset classes, so a class-specific reset inference cannot be promised. The historical scanner hard stop left the complete published generation unchanged; its stored Bank0/0x80 byte predates the failed operation. A fresh ONESHOT would require many bank transactions and is not a one-register read after lockout.

Two other documented default/configured differences are Bank1/0xCA (table §6.1.11 p45: Def.0x00; static final init `0x22` enabling VCLK1/VDO1 only) and Bank1/0xCD (Def.0x46; static final init `0x4A` for phase 10). Neither is in the frozen 82-entry manifest. The current ACQ fixed actions can read only CH1 Bank5/0x05 and 0x08; they cannot accept a host-supplied Bank0/0x80 or Bank1/0xCA/0xCD request. Their cached baseline also can predate a subsequent fault. A hypothetical fixed read would require a separately authorized new image, bank ownership/restore proof, and reset-class characterization; this task adds none.

An observed reset-default-like byte after a verified configured value could also be another writer, wrong bank, lost initialization or unreliable read. A retained configured byte only excludes a reset class *documented* to change that mask, with no intervening reinitialization and a trustworthy fresh read. Correct bank readback alone proves neither presence nor absence of a reset. The exact missing authorities are class-specific reset defaults, direct fresh post-error fixed-read path, and assembled-board reset linkage/voltage. No generic host I2C access or live scan is authorized here.
