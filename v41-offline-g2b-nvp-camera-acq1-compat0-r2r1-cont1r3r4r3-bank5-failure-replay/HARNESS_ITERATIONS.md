# Bounded task-owned harness corrections

The frozen scanner, manifest, fixed master, wrapper and top were never edited. Only task-owned test/checker code changed. Three correction rounds were consumed, within the Owner's maximum of three; no design change or hypothesis-forcing alteration was made.

1. Initial mock testbench used `sequence` as a SystemVerilog identifier. `xvlog` rejected it with `VRFC 10-8549 SystemVerilog keyword 'sequence' used in incorrect context` at the task-owned file. Renaming only that testbench variable to `txn_sequence` allowed compilation. The error was pre-elaboration and did not test the hypothesis.
2. On this Windows Vivado simulator, passing `CASE=1` through `-testplusarg` returned `Expected a switch but found 1`; a dynamic `$test$plusargs($sformatf(...))` then triggered an `xelab` LLVM bad-signature assertion. The final harness uses literal `CASE_1` through `CASE_14` arguments. Neither failure reached simulation. The commands and console diagnostics are preserved in the task execution transcript; no raw source or design setting changed.
3. The first T12/T13 mock run correctly produced 106 commands for one recovered retry and 15 commands for an unrecovered entry retry, but the task checker still applied clean-scan 105 and an incorrectly estimated 10. Original failed logs `logs/T12_mock.log` and `logs/T13_mock.log` remain private. The checker was corrected to assert 106 and 15 without changing stimulus or RTL. All 14 mock cases were rerun as `*_final.log` and passed. The private-record checker was also strengthened to reject a deliberately wrong expected raw hash and a publication-bit mutation before its final T17/T18 run.

Vivado 2025.2 build 6299465 was used only for simulation compilation/elaboration/execution. Its process exit status was **not** treated as sufficient: every final log was scanned for `Fatal:`/`Error:` and required an explicit `TEST_EXECUTION_PASS` marker. Final mock logs: 14/14; pin cases: T15 plus three T16 controls; frozen raw/checker: T17/T18. There was no wider timing sweep, random search, full physical-clock 26-scan replay or fourth harness revision.
