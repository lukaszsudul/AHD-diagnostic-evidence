# Versioned SCAN1 first-attempt telemetry

The exact machine-readable source is `CONT1R3_TELEMETRY_SCHEMA.json`, SHA-256 `438D630943B0D3A2BFCB2C23B9FB060FD0C347C16F331D008997DBB3B8B22F95`. The RTL exposes that digest word-for-word; the host checks it before collection. The sideband is diagnostic, read-only and requires magic `0x4E565433`, version `0x00010000`, capabilities `0x0000007F`, entry count 82, group count 10 and manifest digest `2773DFA86ABEC87EF1E5BFB6F093D83BD8FCB4382B51B1792F3B7E8E302A1B2B`. The older R2R1 image has no valid CONT1R3 magic/digest and must be rejected.

The 64-bit FPGA-native counter runs at 62.5 MHz (16 ns per tick); the host uses unsigned modulo-2⁶⁴ subtraction and a bounded scan duration to reject ambiguous wraps. Ten group records contain successful bank-verify completion ticks and master transaction sequences. Eighty-two entry records contain the first command-acceptance tick, exact current/previous bank, actual group and position, transactions since bank verification, raw and decoded first failure, retry completion and final byte. Even clean entries are recorded as exposure denominators. There is no event-only sampling.

The host reads the frozen legacy snapshot and the complete sideband before ACK, checks generation, immutability, complete exposure set, event count, each physical transaction sequence, aggregate clean-105-plus-retries count, bank restoration, and the immutable projection. It durably flushes the private raw pair and event/exposure rows before ACK. Any mismatch, overflow, hard scanner error or stale image stops the campaign; checkpoints are not resumable.
