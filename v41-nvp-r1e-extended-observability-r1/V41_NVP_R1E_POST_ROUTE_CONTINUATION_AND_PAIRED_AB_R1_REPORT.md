continuation session opened the exact sealed routed DCP, then stopped before
all remaining reports and before bitstream generation because the task-local
identity assertion compared a checkpoint design-object name with the RTL top
identifier. Vivado returned `checkpoint_PHASE3_routed`; the assertion required
`ahd_capture_top_xdma`.

design contradiction. However, the explicit one-session/no-rerun rule controls:
the harness was not patched or executed again. No bitstream write was attempted,
no hardware precheck or FPGA program was performed, and the active FPGA image
