# Protected initialization and runtime I2C ownership

Scope: DIAG0 offline architecture proposal; no implementation or hardware qualification. Normative decisions apply to the future HW0_DIAGNOSTIC profile. Engineering gate is BLOCKED by the explicitly identified NVP evidence gaps; publication does not promote SSOT.


Protocol ownership DEFINED; NVP status/classifier command contents remain partially BLOCKED. Existing autoinit has no runtime command interface. Top wires NVP output-enable as init_release AND probe_release, which is open-drain composition, not an arbitration protocol. PRODUCT has the post-init research probe elaborated out (recovery-4 profile receipt). Never activate that deep historical probe merely to obtain runtime I2C access.

Future owner states NONE,INIT,RUNTIME; all controllers clocked by axi_aclk,62500000Hz. INIT exclusively owns SCL/SDA from startup through qualified initialization, including bank verification, restore, final legal STOP and bus-free confirmation. Runtime requests wait for INIT_DONE && !INIT_BUSY && !INIT_ERROR. Acquisition waits no longer than LOCK_TIMEOUT_MS; failure sets NVP_INIT_NOT_COMPLETE. INIT_ERROR is terminal for live acquisition but must not block synthetic tests.

Ownership transfers only while both released lines are physically sampled high for the proven bus-free interval, neither engine is active and initialization has completed. Gate nonowner release controls to1; owner changes must never synthesize a false START/STOP. Runtime manager serializes complete banked operations: capture/verify current FF, select requested bank with FF write and readback, target operation, verify writes, restore/verify entry bank before relinquishing. On untrusted bank state do not write an unverified cached value; report I2C_ERROR and invalidate status cache. No target write after bank-select failure. Runtime bank cache is distinct and invalidated on ownership changes/reset/failure.

Retain R1i electrical semantics at25kHz: filtered physical SCL high qualification/clock stretching, qualified ACK sampling, first qualified NACK abort, legal STOP, bounded retry/backoff and timeout. Reuse or extract the qualified byte-transaction engine without changing its pre-INIT_DONE behavior. Do not copy a generic unqualified I2C implementation. Verify pre-init output enables and telemetry cycle-for-cycle against accepted R1i vectors. The runtime service adds only post-init transactions, serialized routing/status reads, and small error context.

Scanning/routing writes allowed only while live admission closed and no current frame being acquired. Running live permits read-only active-input status polls; changing route requires loss/stop drain then ROUTING. Synthetic operation may coexist with read-only I2C status polling after INIT_DONE but does not wait for NVP readiness. No runtime NVP reset or power-cycle command is defined in MMIOv1. STOP/ABORT during an I2C operation lets its current legal bus termination and restoration finish; timeout is reported rather than seizing active lines.

I2C_FAILURE packs bank,register,phase,reason and FIRST_ERROR_* preserve failure coordinates. Retry policy: use the qualified engine's bounded recovery for an individual transaction; runtime service adds no unbounded retry or undocumented alternative register write. Recovered and terminal outcomes remain distinguishable in retained R1i observability and the service error context. Exact classifier transaction recipe requires B1 closure before LIVE capabilities can be enabled.
