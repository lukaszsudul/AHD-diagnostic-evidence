# Counter coherency and accounting

Scope: DIAG0 offline architecture proposal; no implementation or hardware qualification. Normative decisions apply to the future HW0_DIAGNOSTIC profile. Engineering gate is BLOCKED by the explicitly identified NVP evidence gaps; publication does not promote SSOT.


SNAPSHOT_COUNTERS copies all diagnostic counters, identifiers, status-cache values, error context and current transport context into a frozen AXI-domain read bank on one AXI edge. Values do not change until the next completed snapshot. Assert BUSY while publishing; increment SNAPSHOT_SEQUENCE after every successful capture; then set VALID and clear BUSY. Command accepted while snapshot busy is ILLEGAL_COMMAND; it does not queue another snapshot. Linux owns an exclusive snapshot mutex across request/wait/all reads/sequence recheck. Read LO then HI (either order is safe in frozen bank). If sequence changed, retry the entire snapshot. Sequence wrap modulo32 is safe under the exclusive lock, never a free-running seqlock that can wrap during a read.

Snapshot acquisition never waits for absent nvp_clk. AXI counters, accepted C2H beats and last coherent NVP status cache are captured immediately. SOURCE_VALID distinguishes valid/fresh live mailboxes from cached/unknown data; INPUT_SAMPLE_AGE_MS gives provenance. This is a coherent AXI-time view of received status, not a simultaneous analog measurement across four inputs. Live source events cross via held event payloads plus acknowledged toggles/Gray counters; unacknowledged events are explicitly unavailable, not guessed zero. The future implementation must reconcile source drops before claiming terminal success.

RUN_ID/CYCLE_ID/SEGMENT_ID are64-bit. FRAMES_REQUESTED/RECORDS_REQUESTED contain ACTIVE per-cycle configured limits widened64 (zero means continuous, not zero frames emitted). CURRENT_FRAME/LINE use header-domain identities widened64; CURRENT_RECORD is cycle ordinal. TICKS is lifetime AXI ticks. All counter registers are snapshot values; STATUS/command acknowledgement is the polling control path. ACTIVE/shadow values are32-bit independent of snapshot and protected by host controller ownership.

For each RUN/CYCLE/LIFETIME scope, frames_started counts admitted line0;frames_completed requires source-closed valid1080-line output;records_emitted increments only at beat511 handshake. bytes_transport_emitted counts8 per accepted AXI beat; bytes_payload_emitted counts8 only for accepted beats8..487. Therefore during a record bytes may exceed4096*records_emitted; at a clean boundary transport=4096*records_emitted and payload=3840*records_emitted. Stall_cycles counts TVALID&&!TREADY AXI ticks. Drop_count counts discarded eligible attempts, not deliberate waiting before eligibility. Discontinuity_count counts controller/source discontinuity events once; ABI flag can describe multiple coalesced events. Abort/source-loss counts each episode once.

Cycle counters reset only at next cycle initialization; run counters only on successful START; lifetime only FPGA/AXI session reset. CLEAR_RUN_STATUS and snapshot do not clear totals. Capture terminal/last-cycle values before resetting cycle counters. LAST_CYCLE_* registers expose latest summary; CYCLE_EVENT_SEQUENCE lets host detect missed cycle metadata. Long autonomous stress is valid without host polling for traffic, but complete per-cycle forensic manifests require host sampling or a future event buffer. EVENT_HISTORY_OVERFLOW or missed sequence means evidence incomplete; never claim lossless historical telemetry from a single latest-summary bank.

CYCLE_EVENT_ACK at0x3F40 is a full-DWORD nonconfiguration acknowledgement of the current CYCLE_EVENT_SEQUENCE. A matching write marks the latest event consumed; a mismatch or partial write rejects without acknowledgement. Each cycle start/end overwrites the latest event summary and increments sequence. Overwriting an unacknowledged event sets sticky EVENT_HISTORY_OVERFLOW; traffic continues, but historical evidence is incomplete. It clears only at a new validated START (after final prior-run evidence is collected), not on a later ACK. CLEAR_RUN_STATUS does not silently repair lost history.
