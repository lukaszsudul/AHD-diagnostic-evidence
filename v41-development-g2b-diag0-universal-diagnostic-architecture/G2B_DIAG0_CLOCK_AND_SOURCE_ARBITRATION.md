# Clock and source arbitration

Scope: DIAG0 offline architecture proposal; no implementation or hardware qualification. Normative decisions apply to the future HW0_DIAGNOSTIC profile. Engineering gate is BLOCKED by the explicitly identified NVP evidence gaps; publication does not promote SSOT.


Use the existing XDMA axi_aclk at 62.5 MHz for both generators, diagnostic ring, controller, scheduler, MMIO and common output formatter. top/ahd_capture_top_xdma.sv lines 39â€“42 and 1218 bind this clock; recovery-4 clocks establish 62.5 MHz. The synthetic path has no readiness/reset dependency on NVP or its IDELAY reference. PCIe reset/clock loss ends the session; it is not a seamless runtime mode switch.

The synthetic video parser consumes up to two ordered bytes each tick (125 MB/s equivalent); it is not a 62.5 MB/s byte-wide bottleneck. Header writing uses separate ticks. Prove two ordered byte steps equivalent to the accepted one-byte transition before synthesis. No new MMCM, PLL, BUFGCTRL or fabric clock mux is required.

Live source processing and RAM write ports remain on nvp_clk; the live read side and all output are on axi_aclk. Live descriptor payloads stay held through synchronized request/acknowledgement, using existing generation/epoch protection. Diagnostic ring has no asynchronous ownership crossing. Only one producer is admitted at a time; synthetic video and record write requests are mutually exclusive by ACTIVE.source_mode. Only one normalized descriptor backend is selected.

Switch sequence: close admission; complete output record; drain all valid records; verify formatter idle and TVALID=0, no outstanding prefetch, no descriptor grant, no pending release for the selected backend; then latch new source on the next valid START. Video graceful boundaries additionally require complete frame closure. Every new START performs an internal stream-state/epoch boundary before any data, with ABI reset semantics. Never gate or switch clocks to obtain this boundary.

Missing live clock: stop admission through an AXI-held disable request; finish any already-owned complete record from live RAM. Quarantine other live slots and unacknowledged tokens. They cannot be released/reused or selected again until nvp_clk resumes, acknowledges disable and a fresh epoch reset, and all old token phases retire. Synthetic backend may then run independently under a new epoch; quarantined live descriptors are excluded. Tag every backend transaction with session/backend generation; late old live acknowledgements cannot alter the new synthetic state. Returning to LIVE waits for quarantine retirement, bounded by LOCK_TIMEOUT_MS; report lock timeout instead of deadlocking synthetic operation. This requires new DIAG1 tests, not reuse of old CDC sign-off without review.

AXI reset asserts as supplied by XDMA. Diagnostic registers/ring reset synchronously in AXI. Source-domain control reset uses the established async assertion/synchronous release discipline. Never reset the output mid-packet for a software ABORT. An actual PCIe reset is an external session termination and requires host reopen/discard.

Alternatives rejected: synthetic producer on nvp_clk fails unplugged operation; unsafe clock mux fails safety; BUFGCTRL adds clock-stop and handover complexity without need; relocating all live ring writes to AXI sacrifices proven CDC structure. Selected separate producers/rings plus common formatter costs extra BRAM and explicit coverage limitations.

Quarantine is an explicit failed-live-run disposition: unowned complete slots cannot be safely granted if the source clock is stopped. Retain their generation/epoch and mark accounting incomplete in SNAPSHOT_SOURCE_VALID until the returning source acknowledges reset abandonment. Do not invent an exact source-drop total while its mailbox is unavailable. Known abandoned records increment drop accounting exactly once at retirement; a host cannot claim the old run PASS. Only the already-owned packet is guaranteed to finish immediately under TREADY. This exceptional source-loss path overrides ordinary graceful/abort drain guarantees and never exposes an abandoned suffix in the new epoch.
