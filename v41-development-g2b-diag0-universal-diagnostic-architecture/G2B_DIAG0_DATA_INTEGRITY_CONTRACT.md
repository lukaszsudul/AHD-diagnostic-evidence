# Hardware and host integrity checks

Scope: DIAG0 offline architecture proposal; no implementation or hardware qualification. Normative decisions apply to the future HW0_DIAGNOSTIC profile. Engineering gate is BLOCKED by the explicitly identified NVP evidence gaps; publication does not promote SSOT.


Host captures only fixed4096-byte boundaries; never scans for magic after corruption. Accumulate short reads into full records without changing boundaries. EOF/partial final record is capture failure. Compare magic4C444841,version00004101,fixed64-byte header selected by version,payload_length3840,reserved bits zero,padding bytes3904..4095 zero. Hardware asserts TKEEP=FF on every beat, TLAST only beat511, stable TVALID/TDATA/TKEEP/TLAST under stall, exactly512 accepted beats per record, no descriptor release before final handshake. Host cannot observe TKEEP/TLAST directly from a raw file; those checks need RTL assertions and later hardware protocol telemetry.

Validate all16 header words against ABI reference. Enforce one logical channel0,active_count1,legal physical input0..3 and expected live mapping; synthetic input0 is a fixture. SOF iff line0;line<=1079;VALID1. Track source frame/capture modulo32,attempt gaps including failed eligible lines,global sequence without unexplained gaps/duplicates within epoch,slot0..3 and24-bit generation. No source identity or pattern fields are written into reserved bits. At epoch change discard partial frames, clear continuity baseline and require first global0. Host binds every accepted epoch/cycle/source mapping to RUN_ID manifest; old buffered data is drained/closed before START, no mid-epoch attach.

Video frame acceptance requires exactly lines0..1079, same source_frame_sequence/input/epoch, expected SOF and no discontinuity/drop/malformed/abort, plus complete closure. A source change, sequence gap, new SOF before expected end, or loss manifest invalidates that frame. Diagnostic frame ledger tracks source closure and emitted lines, not merely observed final-line source event. Host compares final completed frame count and file accounting to coherent terminal snapshot. No promise that a live frame's emitted prefix can be retracted after signal loss.

Pattern checks: regenerate every payload byte with normative formula and manifest R/C/expected Q/F/L. Distinguish structural integrity from deterministic correctness. Hardware knows generator counters/ring ownership and asserts internal pattern sequencing/seed continuity; full independent byte comparison is host-side. PATTERN_ERROR must be driven by actual internal self-check/invariant failures, not advertised as an independent full hardware golden validator.

Successful clean synthetic record cycle: records_emitted=RECORD_LIMIT (when count caused stop);transport=4096*N;payload=3840*N;drop0;no unexplained attempt/global gap. Successful video cycle:F=FRAME_LIMIT,records=1080*F,transport=4423680*F,payload=4147200*F,invalid frames0 (when count caused stop). Time/host stop/abort/source loss have distinct reason codes; do not assert count-limited equality for those. Any unexplained missing/duplicate record, stale manifest association, pattern mismatch or evidence event gap fails the affected test.
