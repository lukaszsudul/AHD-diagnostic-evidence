# Unchanged transport ABI

Scope: DIAG0 offline architecture proposal; no implementation or hardware qualification. Normative decisions apply to the future HW0_DIAGNOSTIC profile. Engineering gate is BLOCKED by the explicitly identified NVP evidence gaps; publication does not promote SSOT.


TRANSPORT_ABI_CHANGE=NO. AHD_C2H_TRANSPORT_ABI_V1, numeric1, record_version0x00004101, little endian,4096-byte record,64-byte header,3840-byte payload,192-byte zero padding,64-bit AXI,512 beats. No header-length field exists: it is fixed by record version. Do not add a field or store diagnostic metadata in padding/reserved flag bits.

The copy G2B_DIAG0_ABI_REFERENCE.json is semantically identical to recovery-4/raw/V41_C2H_TRANSPORT_ABI_V1.json and retained only for audit; it does not change the source authority. All16 header fields remain at offsets0,4,...60. It already encodes frame,line,reset epoch,slot generation,capture/attempt/global sequences,logical channel,physical input and discontinuity.

Diagnostic RUN_ID/CYCLE_ID/SEGMENT_ID, source/pattern/seed and build profile are out-of-band MMIO+host run manifest. Physical_input_id0..3 is already legal for live mapping; logical_channel_id0 and active_count1 remain constant. Synthetic records retain physical_input_id0 as a fixture mapping, interpreted under diagnostic MMIO mode (never invent physical ID4 or7). Source-frame and capture sequences persist through ordinary enable/disable and transport resets, as ABI requires. New diagnostic source instances retain their own sequence state throughout the FPGA session. A switch creates a new transport epoch; it does not reset either source's frame/capture state.

flags:SOF bit0 iff line0;DISCONTINUITY bit2 only same-epoch continuity breaks;OVERFLOW_OCCURRED bit3 only ring-full drops;MALFORMED_PRECEDING bit4 only validation failures;VALID bit5 for complete validated virtual/real lines;WINDOW_END bit6 remains0 for this DMA path;bit1 and7..31 remain0. On transport epoch reset old pending flag context clears after accounting. Never stream VALID=0 to represent ABORT. Record and frame invalidation are different: an aborted frame may contain valid line records which the host discards as a frame.

The formatter assigns global_stream_sequence only when locking a complete descriptor, freezes it through TLAST, and consumes it on successful completion. Source line eligibility consumes attempt even if later dropped; synthetic waiting before eligibility is a stall. Reset epochs restart global/attempt/generation counters per ABI, while source frame/capture state persists. At every successful START/cycle, internal RESET_STREAM_STATE and epoch-completion handshake precede enabled output. The host records exact epoch and first sequence, never attaches mid-epoch.

Existing G2B MMIO addresses/semantics remain unchanged. A legacy writer can still disrupt diagnostic control; the Linux single-owner contract prohibits writing old transport/reset controls during a diagnostic run. Firmware must observe an externally induced legacy reset/disable, cancel the diagnostic session with LEGACY_CONTROL_CONFLICT, account invalidated state, and require re-negotiation. Do not silently block or repurpose legacy writes. For a legacy reset explicitly abandoning an in-flight packet, record an external session termination (same ABI reset behavior), not successful DIAG graceful stop.
