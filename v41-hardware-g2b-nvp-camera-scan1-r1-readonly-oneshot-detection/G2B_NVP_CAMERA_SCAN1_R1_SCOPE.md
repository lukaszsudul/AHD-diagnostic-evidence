# Scope

The authorized implementation is a diagnostic-only, read-only, bank-atomic four-channel NVP scanner. It may issue only internal bank-select writes to register `0xFF`; generic host I2C writes and all functional NVP configuration writes are absent. The scanner has no functional fanout to PRODUCT video, parser, C2H, DMA, route, EQ, mode or BGDCOL controls.

This publication contains no bitstream, DCP, driver, native binary, credential, vendor PDF, reference-repository file, camera image or video frame.
